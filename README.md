# OpenSource

This is a small project that aims to recreate the source engine using C99 and some simple libraries!

Feel free to help! There is a coding style guide in the source folder called the style-guide.txt!

Everything is free to use and you can clone the project for your own work, or just to have some fun!

## Contribution

If you are willing to contribute to the project in some way, just make a fork add your changes and make a pull request!

Very simple! I hope that this makes it easier for new people to begin their graphics programming journey, and I will be really happy if I help someone with something that they are stuck on trying to figure out!
